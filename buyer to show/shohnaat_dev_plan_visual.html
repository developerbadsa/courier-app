Database Schema & Relational Structure

PostgreSQL schema design normalized for data integrity, financial auditing, and high transaction volume.

Prisma ORM
User & Merchant P1
  • PK id UUID
  • email / phone String
  • role (ADMIN|MERCHANT|RIDER)
  • FK user_id User
  • business_name String
  • default_zone Zone
  • api_key P2 Token
Shipment & Log P1
  • PK id UUID
  • tracking_no Unique Str
  • FK merchant_id Merchant
  • FK pickup_id PickupReq
  • cod_amount Decimal
  • delivery_fee Decimal
  • status Enum
  • FK assigned_rider_id
Hub & Transfers P3
  • PK id UUID
  • branch_name String
  • city / zone String
  • PK manifest_id UUID
  • FK from_hub_id Hub
  • FK to_hub_id Hub
  • parcel_count Int
  • driver_name String
Finance & Ledger P2/P4
  • PK id UUID
  • FK shipment_id Shipment
  • collected_cod Decimal
  • net_merchant_payout
  • settlement_status
  • PK ledger_entry_id
  • debit_account Str
  • credit_account Str
