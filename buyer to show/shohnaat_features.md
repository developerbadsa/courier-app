# Shohnaat Logistics System — Feature List

> Source: `Shohnaat_Logistics_System_Development_Proposal_No_Budget.pdf`

---

## ⚠️ STRICT DECISIONS — DO NOT CHANGE

> These are **locked client decisions**. Every document, mockup, and calculator must follow them — no exceptions.

1. **💳 Payment gateway: PayPal / Stripe ONLY.**
   - bKash, Nagad, SSLCommerz, ShurjoPay are **NOT allowed** — this is an **international** project, not Bangladesh.
   - Any new feature/doc mentioning mobile-banking gateways must use PayPal or Stripe instead.
2. **💵 Currency: USD only.**
   - **Never use BDT** anywhere (documents, mockups, calculators, examples).
   - Demo amounts in the visual file use USD (e.g., `$15.00` COD, `$1.20` fee).
3. **Applicable files:** `shohnaat_dev_plan_visual.html` (V3), `shohnaat_dev_plan_dev.html`, `shohnaat_dev_plan.html`.

## 1. Customer & Merchant Management 👥

- [ ] Register and manage customer and merchant information
- [ ] Set customized shipping prices based on services and regions
- [ ] Manage payment methods, settlements, and account statements
- [ ] Create customer user accounts for shipment management and tracking

## 2. Pickup & Shipment Management 📦

- [ ] Register and track pickup requests
- [ ] Assign pickup tasks to representatives
- [ ] Receive shipments at warehouses for sorting and preparation
- [ ] Transfer shipments between branches and warehouses
- [ ] Automatically generate delivery lists
- [ ] Track shipment status throughout the delivery process
- [ ] Manage uncovered delivery areas and rejected shipments
- [ ] Support partial shipment receiving and returns

## 3. Delivery Representative Management 🚚

- [ ] Register and manage delivery representatives
- [ ] Track representative movements in real time
- [ ] Manage cash collection from representatives
- [ ] Handle representative advances and commission payments
- [ ] Provide internal communication between representatives and merchants

## 4. Shipment Tracking & Notifications 🔔

- [ ] Track all shipment operations and status updates
- [ ] Provide real-time shipment visibility
- [ ] Send WhatsApp and phone notifications to customers
- [ ] Update merchants with important shipment information

## 5. Merchant Website Integration 🌐

- [ ] Integrate the system with merchant websites
- [ ] Enable real-time data synchronization
- [ ] Support API integration for shipment and customer data

## 6. Accounting & Financial Management 💰

- [ ] Manage shipping charges and collections
- [ ] Issue debt invoices for customers and merchants
- [ ] Manage customer settlements and account statements
- [ ] Track administrative expenses
- [ ] Support general and subsidiary ledgers
- [ ] Generate trial balances, profit and loss reports, balance sheets, and other required financial reports

## 7. Deliverables 📋

- [ ] A complete logistics management system based on the agreed scope
- [ ] Customer and merchant management functionality
- [ ] Shipment, pickup, warehouse, and delivery management
- [ ] Delivery representative management and tracking
- [ ] Shipment tracking and notification features
- [ ] Financial and accounting management features
- [ ] API integration capabilities
- [ ] Testing and final system review
- [ ] Two weeks of development and implementation
